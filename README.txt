CONTACT BUTTON:
The "Send Me an Email" button uses a mailto link. It opens the visitor's default email app with your email address and a prepared subject. If no email app is configured on their device, they can copy/use nikampurab105@gmail.com, which is also shown on the page.

PUBLISH USING GITHUB PAGES:
1. Create a public repository named purab-nikam.github.io.
2. Upload index.html, style.css, script.js and the assets folder.
3. Open Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. After GitHub Pages finishes publishing, visit https://purab-nikam.github.io/
